# Video slots

Drop a file here with the exact name below, rebuild (`npm run build`), and it
replaces the designed placeholder automatically. Nothing else needs editing.

**Every clip:** MP4 (H.264), muted, seamless loop, **no text burned in** (the
site overlays text so it stays readable and searchable), ≤ 4 MB, consistent
grade — deep charcoal blacks, warm ivory highlights, muted gold accents.

**Optional extras per slot**
- `<name>.jpg` — poster still shown while the video loads (same aspect ratio).
- `<name>-mobile.mp4` — vertical 9:16 cut used on phones.
